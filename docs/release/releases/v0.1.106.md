# Curatorr v0.1.106

## Summary

This release adds a playlist watch folder, so playlists generated by another tool are imported and kept up to date automatically. It also fixes TIDAL playlist import, which failed for every playlist with normal TIDAL developer apps.

## Added

- **Playlist watch folder**: admins set a folder in **Settings → Playlists → Playlist Watch Folder**. Each `.m3u` or `.m3u8` file in it becomes one imported playlist, named after the file. Editing a file refreshes its playlist, unchanged files are skipped, and a renamed file is imported as a new playlist. Subfolders up to four levels deep are included.
- **Matching artwork**: an image with the same base name as a playlist file (`.jpg`, `.png` or `.webp`, up to 5 MB) becomes the playlist artwork on Plex. Replacing the image updates the artwork, and removing it switches back to automatic artwork.
- **Owner and sharing**: watch-folder playlists belong to one admin-chosen user and can be shared as global playlists, copied to every user.
- **Removed files**: a playlist whose file is removed is kept and marked **Source missing**. Turn on **Delete playlists whose file is removed** to delete it instead. A watch-folder playlist deleted in Curatorr is not re-imported until its file changes.
- **Playlist Watch Folder job**: scans every 15 minutes by default (adjustable under **Settings → Jobs**). The settings card has **Scan now** and a **Tracked files** list showing each file's status.
- **Refresh import** on a watch-folder playlist rereads the current file, falling back to the copy stored at the last import.

## Fixed

- Fixed TIDAL playlist previews and imports failing with "includeLinkage requires INTERNAL access tier", from both the TIDAL tab and the URL tab. Curatorr now requests the playlist owner with TIDAL's standard `include` parameter, and reads the playlist without owner details if TIDAL refuses that.
- Added regression tests for watch-folder imports, unchanged and edited files, artwork changes, removed files, manual refresh, and the TIDAL playlist request.

## Upgrade Notes

- Update the Curatorr app image and recreate the container as usual. No analyzer update is required.
- To use the watch folder, mount the folder into the container (for example `./playlists:/app/playlists:ro`), then set the path and owner in **Settings → Playlists**. The watch folder is off until you turn it on.
- Generators should write each playlist under a temporary name and rename it when complete, keep filenames stable, and include `#EXTINF` artist/title lines.
- A new database table is created automatically on startup.
- Details: `docs/wiki/Playlist-Imports.md#watch-folder`.
