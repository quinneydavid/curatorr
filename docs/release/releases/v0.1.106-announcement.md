# Curatorr v0.1.106 Announcement

Curatorr `v0.1.106` adds a playlist watch folder and fixes TIDAL import.

## Highlights

- **Playlist watch folder**: drop `.m3u`/`.m3u8` files into a folder and Curatorr imports them, refreshes them when they change, and can share them with every user.
- **Matching artwork**: an image with the same name as the playlist file becomes its Plex artwork.
- **TIDAL import fixed**: previews and imports no longer fail with "includeLinkage requires INTERNAL access tier".
